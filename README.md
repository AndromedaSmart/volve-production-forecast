# Прогноз добычи нефти и газа месторождения Volve

Месячный прогноз добычи нефти и газа по месторождению на 6 месяцев вперёд по истории до даты отсечения. Данные: открытый набор Volve (Equinor, 2007–2016), файл `data/data.xlsx`.

**Текущая версия — v3** (ветка `v3-direct-forecast`). Материалы версии 2 (Арпс, LightGBM, Transformer, CSDI, `REPORT.md`, `METHODOLOGY.md`, `FIGURES.md`, `docs/report.docx`) сохранены без изменений и относятся к предыдущему этапу.

## 1. Описание решения

**Задача.** По месячной истории добычи построить прогноз нефти и газа на 6 месяцев. Качество проверяется на пяти контрольных окнах (отсечения: декабрь 2009, 2011, 2013, 2014, 2015). Метрика окна — WAPE, итоговая — RMS WAPE по пяти окнам.

**Подход v3.**
- Шесть отдельных моделей Ridge для горизонтов 1…6 месяцев: без рекурсии, без линейного индекса времени и календарных признаков.
- Признаки: лаги 1/2/3/6, средние за 3 и 6 месяцев, разброс за 6 месяцев; все значения нормируются уровнем последних шести месяцев на дате прогноза.
- Внутренний выбор процедуры среди: среднее 6 мес., медиана 6 мес., последнее значение, Ridge, Ridge + log1p(вода/нефть); alpha = 1/10/100. Выбор делается только по внутренним отсечениям −6/−12/−18 месяцев, контрольное окно не используется. Если истории недостаточно (окно 1), заранее задано правило «среднее 6 мес.».
- Дополнительно проверены сумма прогнозов по скважинам и физический признак log1p(вода/нефть) — как гипотезы.
- Основной прогноз использует только историю. Сценарий с фактическими будущими часами работы (`oracle`) считается отдельно и не является прогнозом по настоящему плану.

**Что изменено по замечаниям наставников.**

| Замечание | Что сделано |
|---|---|
| Убрать номер месяца из регрессии, смотреть на уровень | Удалены индекс времени и календарные признаки |
| Не использовать рекурсию | Прямые горизонты 1…6 |
| Сравнить со средним и медианой за полгода | Оба правила — фиксированные базовые линии |
| Плановые часы и «подглядывание» | Основной прогноз без будущих часов; фактические часы — только oracle |
| Модели по скважинам | Сумма скважинных прогнозов, новые стволы не добавляются задним числом |
| Физический признак ln(ВНФ) | Проверен log1p(вода/нефть) |
| Графики ошибок на обучении и тесте | 28 рисунков, обучающие подписаны как in-sample |
| Кривая автовыбора на T1–T5 | Выделена жирной линией с подписью выбранной модели |

## 2. Текущие результаты

RMS WAPE по пяти окнам, %, только история:

| Подход | Нефть | Газ |
|---|---:|---:|
| Автовыбор | 29.25 | 26.22 |
| Медиана 6 мес. | 29.35 | 26.36 |
| Среднее 6 мес. | 31.29 | 27.72 |
| Скважинная медиана | 27.67 | 24.70 |
| Скважинный автовыбор | 39.09 | 30.45 |
| Ridge, alpha=10 | 34.62 | 31.39 |
| Ridge + log1p(вода/нефть) | 79.58 | 82.88 |

Автовыбор по окнам, WAPE %: окно 1 — 27.4 / 26.4, окно 2 — 12.9 / 15.3, окно 3 — 21.5 / 18.1, окно 4 — 29.5 / 24.9, окно 5 — 45.1 / 39.4 (нефть / газ).

**Выводы и границы.**
- Автовыбор лишь немного лучше медианы за полгода.
- Скважинная медиана лучше ретроспективно, но выбирать победителя по тем же пяти окнам нельзя.
- Физический признак нестабилен: помогает в окне 2, разрушает окно 1; универсальный выигрыш не подтверждён.
- Пять окон уже изучались при разработке: это ретроспективная оценка, а не независимый тест.
- Скважинная модель не покрывает новые стволы: 23.2% нефти окна 3 и 8.9% окна 5.
- Настоящего архивного плана часов нет. У F-1 C отсутствуют часы за май–июнь 2016, поэтому метрика oracle для окна 5 не определена.
- Арпс, LightGBM, Transformer и CSDI в схеме v3 не пересчитывались.

## 3. План до финала

1. Единый протокол для всех моделей (Арпс, LightGBM, Transformer, CSDI) в схеме v3.
2. Независимая проверка: зафиксировать выбор и оценить на новых данных или отложенном периоде.
3. Обработка новых стволов (cold start) или явный сценарий с планом бурения.
4. Прогноз по архивному плану часов, если план доступен.
5. Уточнение и проверка физических признаков (ВНФ, давление).
6. Интервалы неопределённости прогноза.
7. Финальная презентация, отчёт и README.

Состав и порядок — предложение команды для обсуждения с наставниками.

## 4. Вопросы наставникам и тьюторам

1. Что считать ВНФ: отношение воды к нефти или иную величину? Как обрабатывать нулевую нефть и воду?
2. Можно ли считать часы известными заранее? Есть ли архивный план ремонтов и остановок на даты отсечения?
3. Как оценивать итог: по объёмам или по удельному дебиту?
4. Допустимо ли выбирать итоговую модель по пяти окнам без независимого теста? Можно ли получить отложенный период?
5. Как поступать с новыми стволами: исключать, моделировать cold start или использовать план бурения?
6. Нужна ли в финале скважинная постановка или достаточно месторождения целиком?

## Как запустить

Нужен Python 3.9+ и пакеты `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `openpyxl`, `python-docx`.

```bash
python volve_v3.py --data data/data.xlsx --out reports/v3
```

Скрипт считает метрики и собирает в `reports/v3` CSV-таблицы, 28 графиков (`figures/`), Word-отчёт `Volve_v3_report.docx` и Excel `Volve_v3_metrics.xlsx`.

## Что внутри

- `volve_v3.py` — расчёт v3, графики, Word и Excel.
- `docs/V3_README.md` — краткое описание метода v3.
- `data/data.xlsx` — исходные данные.
- `src/`, `run_all.py`, `solution.ipynb`, `colab.ipynb`, `REPORT.md`, `METHODOLOGY.md`, `FIGURES.md` — материалы версий 1–2 (результаты v2 были получены другим протоколом и не сопоставимы напрямую с v3).
